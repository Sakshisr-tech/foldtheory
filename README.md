# Fold Theory

An editorial portfolio for Fold Theory, a New Delhi studio focused on custom
packaging, print, gifting, hospitality, and product presentation.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run lint
npm run build
```

The portfolio photography is sourced from Fold Theory's official public studio
archive. Full project specifications and testimonials are intentionally left
unclaimed where approved source material was not available.
